# Midship Drift

An arcade sprite-scaling racer in the spirit of the late-80s "super scaler" cabinets:
roller-coaster roads on stilts, crests you can fly off, a pack of rivals, and Leo's MR2
as the star car. It runs in any browser with no build step.

| Version | Folder | What's different |
| --- | --- | --- |
| **II** (current) | [`v2/`](v2/) | Pre-rendered sprite sheets made from 3D models, painted horizons, nine-pose cars with brake lights |
| I | [`v1/`](v1/) | Everything drawn from code at load time, no image files at all |

Play by opening `v2/index.html` (or `index.html` here, which forwards to it). Controls,
courses and the sprite pipeline are described in each version's README.

All art, music and sound are original. Nothing is taken from any existing game.
