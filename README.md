# Midship Drift

Arcade racers in the spirit of the late-80s "super scaler" cabinets, with Leo's MR2 as
the star car. They run in any browser with no build step.

| Version | Folder | What's different |
| --- | --- | --- |
| **III** (newest) | [`v3/`](v3/) | Knotted circuits that cross over and under themselves, real drifting with turbo boosts, cartoon racers with a face-per-position bar and a winged START sign |
| II | [`v2/`](v2/) | Roller-coaster roads on stilts. Pre-rendered sprite sheets made from 3D models, painted horizons, nine-pose cars with brake lights |
| I | [`v1/`](v1/) | The same roads with everything drawn from code at load time, no image files at all |

Play by opening `v3/index.html` (or `index.html` here, which forwards to it). Controls,
courses and how each version works are described in each version's README.

All art, music and sound are original. Nothing is taken from any existing game.
